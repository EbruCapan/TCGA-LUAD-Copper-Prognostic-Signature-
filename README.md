# TCGA-LUAD copper homeostasis prognostic signature: reproducibility scripts

These scripts were reconstructed from an available R console history. They are **not** a complete analysis pipeline.

- `scripts/U5_Time_Dependent_ROC.R`: recalculates 1-, 3-, and 5-year time-dependent ROC curves and pointwise confidence intervals using `timeROC`, starting from an upstream **patient-level six-gene risk score** RDS. Requires the input at `drug_sensitivity/results/U2_6Gene_504/TCGA_504_Final_Risk_Groups.rds` and must be run from the project root. It does not derive the six-gene score or independently validate it.
- `reproducibility/U6_Software_Versions.R`: records versions of the current R environment and `sessionInfo()`.

**Data access:** The TCGA-LUAD source data should be obtained through the relevant GDC/TCGA access channels subject to their data-use terms. The risk-score input is generated by upstream analysis and is not bundled here. The complete preprocessing and risk-score derivation pipeline must be supplied before the ROC analysis can be reproduced from source data.

**Verification:** Scripts have been reviewed against console history but have not been executed against the original local project data in this environment. Review generated values against the published results before release.
